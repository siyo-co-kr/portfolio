## 배경

EMR 화면을 직접 조작하는 RPA로, 각 버튼과 입력란을 **화면 좌표로 지정해 클릭**하는 구조였습니다.

## 문제

EMR UI 업데이트 후 화면 요소의 위치가 전부 바뀌어, 좌표에 의존하던 자동화가 일괄로 오작동했습니다.

## 원인 분석

- 요소의 배치와 간격은 그대로이고 **전체 위치만 이동**한 것을 확인했습니다.
- 좌표를 하나하나 다시 지정하는 대신 구조적으로 해결할 수 있다고 판단했습니다.

## 해결

1. 화면에서 **기준점**이 되는 요소를 먼저 탐색
2. 각 클릭 대상을 절대 좌표가 아닌 **기준점으로부터의 상대 거리**로 관리
3. 실행 시 기준점 위치를 다시 계산해 실제 클릭 좌표를 구하도록 변경

## 결과

- 좌표 전체를 다시 설정하지 않고 복구
- 이후 위치 이동, 해상도·창 크기 차이 등 같은 형태의 UI 변경에 **수정 없이 자동 대응**
